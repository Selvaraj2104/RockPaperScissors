# 🎮 Rock–Paper–Scissors Game (HTML / CSS / JavaScript)

## 🧩 Overview
This is a simple interactive **Rock–Paper–Scissors** game built using **HTML, CSS, and JavaScript**.  
The user plays against the computer for **5 rounds**, and the game tracks scores, displays round results, and shows the final winner.

---

## 🚀 Features
- 🎛️ Three buttons — **Rock**, **Paper**, **Scissor**
- 🤖 Computer makes a **random choice**
- 🧮 Updates user & computer scores in real-time
- 🔢 Shows current round (1/5)
- 🏆 Declares **final winner** after round 5
- 🔄 Reset button resets entire game
- ⚡ Instant round feedback

---

## 🧠 How It Works
1. User selects Rock / Paper / Scissor  
2. Computer randomly picks one  
3. Game compares both choices  
4. Displays:
   - 🎉 User Win  
   - 👾 Computer Win  
   - 🤝 Tie  
5. Updates:
   - User score  
   - Computer score  
   - Round number  
6. After 5 rounds → Shows the final winner with color highlight  
7. Reset button clears all values
